Data policy

Effective 8 November 2026

Zero data retention

650 Group AI does not store the content of requests to our inference API. Prompts, files, tool definitions and model outputs are processed in memory to produce the response and are discarded when the response is complete. We do not write request or response content to disk, logs or databases.

No training on your data

We never use prompts or outputs to train, fine-tune or evaluate models, and we never sell or share them.

What we do record

For billing, capacity planning and abuse prevention we keep request metadata only:

  • time of the request, model name, and which API key (or routing partner) sent it;
  • number of prompt and output tokens, response time, and whether the request succeeded, was refused as busy, or failed;
  • a request ID supplied by the caller or routing partner, if any.

Metadata never contains request or response text. We keep it for up to 12 months for billing records, then delete it.

Where requests are processed

Requests are served from GPU servers that we rent from data-center providers, currently in the United States. Our inference engine is configured not to log request content, and rented servers are deleted, with their disks, when we stop using them.

Changes and questions

If this policy changes we will update this page and its effective date before the change applies. Questions: info@650group.ai.
