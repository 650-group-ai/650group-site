What we do

GPU inference benchmarks

We measure output speed, prompt processing speed and time to first token across GPU generations under identical settings, and price the results per million tokens.

Model quality testing

Our own test suites cover maths, knowledge, instruction following and tool calling, checked against public benchmarks, so we know a model behaves before we serve it.

Model hosting

We run open-weight models on rented data-center GPUs behind an OpenAI-compatible API, with spending limits and capacity controls built in.

How we work

  • OpenAI-compatible chat completions API with streaming and tool calling.
  • Each model is tested for speed and quality on the exact hardware and settings we serve it on.
  • Clear, published per-token pricing and declared capacity; we return a "busy" signal rather than letting requests queue.
